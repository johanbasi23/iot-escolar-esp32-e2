# Video 17 | Barrera de Acceso Inteligente con Bluetooth[cite: 2]

- **Simulación en Wokwi:** `https://wokwi.com/projects/481245765034704897`
- **Archivos incluidos:**
  - `barrera_bluetooth.ino`: Adaptado para probar el ingreso de clave desde el Monitor Serie en Wokwi[cite: 2].
  - `barrera_bluetooth_esp32_real.ino`: Código completo con `BluetoothSerial.h` para controlar desde un teléfono Android (app *Serial Bluetooth Terminal*)[cite: 2].
- **Conexiones:** Servomotor (`PWM` en `GPIO 18`, `V+` en `5V/VIN`), LED indicador (`GPIO 4` con resistencia de 220 Ω a `GND`)[cite: 2].
